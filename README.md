# signal-lab · 信号与系统交互式实验室

把《信号与系统》里最抽象的几个概念，做成**可以拖参数、当场看变化**的网页。

不背公式，先动手。

## 模块一览

| 模块 | 内容 | 可以亲手验证什么 |
| --- | --- | --- |
| ① 基础信号 | 正弦波的频率 / 幅度 / 相位 | 频率、周期、相位之间的关系 |
| ② 傅里叶级数 | 用 N 个谐波逼近方波 | 吉布斯现象、只有奇次谐波、幅度按 1/n 衰减 |
| ③ 采样与混叠 | 采样率与信号频率的关系 | 奈奎斯特定理、混叠产生的假频率 |
| ④ 滤波器设计 | 巴特沃斯低通 / 高通 / 带通 / 带阻 | 阶数 N 与阻带斜率、-3 dB 截止频率 |

## 本地运行

```bash
python3 -m pip install streamlit numpy scipy plotly
streamlit run app.py
```

浏览器打开 http://localhost:8501

## 技术栈

- **Streamlit** — 把 Python 脚本直接变成网页，不用写一行前端
- **NumPy / SciPy** — 信号生成、FFT、Butterworth 滤波器设计
- **Plotly** — 可缩放、可悬停的交互式图表
